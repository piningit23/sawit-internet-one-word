One word for the whole internet: **brainrot**. A tiny Python program that writes the word to `/output/entry.txt` for the make.fun judge to compare against other entries. Eight letters, funny on its own, true of the entire internet — an endless feed that melts attention into mush — and not the first obvious word anyone reaches for.

## Run it

```sh
python3 main.py
```

It writes one word (8 characters, no trailing newline) to `/output/entry.txt`. Python 3.13, standard library only, deterministic, no network.
